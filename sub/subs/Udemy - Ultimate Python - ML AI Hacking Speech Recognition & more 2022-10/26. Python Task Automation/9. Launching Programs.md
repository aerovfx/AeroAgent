# 9. Khởi chạy chương trình

---

Trong bài giảng này, chúng ta sẽ tìm hiểu cách khởi chạy chương trình bằng mã Python ở đầu mã,

chúng tôi sẽ nhập mô-đun quy trình con pythons.

Tiếp theo, chúng ta sẽ sử dụng chức năng mở của nó để mở một chương trình trên máy tính của mình.

Chỉ cần có đường dẫn tới file Excel của nó là bạn có thể mở bất kỳ chương trình nào bạn muốn.

Với ví dụ này, chúng ta sẽ mở Ms Paint.

Hãy gọi quy trình con dot p. mở và chuyển vào đường dẫn tệp sau C dấu hai chấm sau đó hai cửa sổ gạch chéo

hai dấu gạch chéo ngược là hệ ba mươi hai hai dấu gạch chéo ngược là Ms Pinked XY.

Khi chúng tôi chạy mã, bạn sẽ nhận thấy rằng sơn đã được mở trên máy tính của chúng tôi.

Chúng tôi cũng có thể sử dụng mã Python để mở xung quanh trong trình duyệt Web để thực hiện việc này, chúng tôi có thể sử dụng Python

Mô-đun trình duyệt web ở đầu mã.

Chúng ta sẽ gõ import Web browser.

Chúng ta có thể sử dụng module này, chức năng mở, mở URL trong trình duyệt Web, hãy gõ Web browser open

và chuyển vào www.youtube.com khi chúng tôi chạy mã.

Lưu ý rằng bạn đang đăng nhập trang web vào trình duyệt web.

Trong bài giảng tiếp theo, chúng ta sẽ học cách sử dụng Python để tự động hóa GUI của bàn phím và chuột.
