# 4. 5 thế hệ ngôn ngữ lập trình

---

Trong bài giảng này, chúng ta sẽ tìm hiểu về 5 thế hệ ngôn ngữ lập trình kể từ khi lập trình

bắt đầu vào năm 1945, đã có năm thế hệ ngôn ngữ lập trình, năm thế hệ

ngôn ngữ lập trình từ một đến năm trên ngôn ngữ máy, ngôn ngữ hợp ngữ, ngôn ngữ cấp cao,

ngôn ngữ định hướng vấn đề và ngôn ngữ tự nhiên.

Thế hệ ngôn ngữ lập trình đầu tiên là ngôn ngữ máy.

Ngôn ngữ máy là mã duy nhất mà máy tính có thể thực sự hiểu được.

Nó biểu diễn dữ liệu dưới dạng số một và số không.

Mặc dù ngôn ngữ máy rất khó đối với con người nhưng những lập trình viên đầu tiên đã viết mã và máy

ngôn ngữ.

Thế hệ ngôn ngữ lập trình thứ hai là hợp ngữ.

Ngôn ngữ hội là ngôn ngữ lập trình cấp thấp, nghĩa là nó gần với ngôn ngữ máy.

Tuy nhiên, nó dễ hơn ngôn ngữ máy vì nó cho phép người lập trình sử dụng dễ dàng ghi nhớ.

các từ trái ngược với số một và số không.

Thế hệ ngôn ngữ lập trình thứ ba là ngôn ngữ cấp cao.

Các ngôn ngữ mà bạn có thể quen thuộc như Java, C++ và Python đều là những ví dụ về

ngôn ngữ cấp độ.

Python là ngôn ngữ lập trình cấp cao và là ngôn ngữ chúng ta sẽ sử dụng trong khóa học này.

Thế hệ ngôn ngữ lập trình thứ tư là ngôn ngữ hướng tới vấn đề hoặc ngôn ngữ cấp độ rất cao.

Một ví dụ về phần tiếp theo của ngôn ngữ lập trình thế hệ thứ tư.

Ngôn ngữ truy vấn có cấu trúc, thế hệ thứ năm của ngôn ngữ lập trình là ngôn ngữ tự nhiên.

Ngôn ngữ tự nhiên chủ yếu được sử dụng để lập trình trí tuệ nhân tạo.

Bài giảng tiếp theo sẽ giải thích Python là gì và tại sao bạn nên sử dụng nó để viết chương trình máy tính.
