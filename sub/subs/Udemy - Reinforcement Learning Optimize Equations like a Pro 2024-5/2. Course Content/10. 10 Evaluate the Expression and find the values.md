# Đánh giá Biểu thức Toán học với Học Tăng cường

## Giới thiệu

Trong dự án cuối cùng này, chúng ta sẽ xây dựng một ứng dụng cho phép người dùng:
1. Nhập bất kỳ biểu thức toán học nào với các biến x, y, z
2. Tìm giá trị tối ưu của các biến bằng thuật toán học tăng cường

## Ví dụ Biểu thức

### Ví dụ 1

Biểu thức:
$$
3x + y^2 + z - 232 = 0
$$

**Kết quả tìm được**:
- $x = 2.64$
- $y = 5.3$
- $z = 4.7$
- Thay vào: $3(2.64) + 5.3^2 + 4.7 - 232 \approx 0$ ✓

### Ví dụ 2

Biểu thức:
$$
2x + \frac{y}{2} + \frac{z}{3} - 135 = 0
$$

**Kết quả tìm được**:
- $x = -1.2$
- $y = 2.7$
- $z = 5$
- Thay vào: $2(-1.2) + 2.7/2 + 5/3 - 135 \approx 0$ ✓

### Bước 2: Thay thế biến

```python
def evaluate_expression(expression, x, y, z):
    expr = expression.replace("x", str(x))
    expr = expr.replace("y", str(y))
    expr = expr.replace("z", str(z))
    return eval(expr)
```

### Bước 3: Tính Reward

```python
def calculate_reward(expression, x, y, z):
    value = evaluate_expression(expression, x, y, z)
    return 100 - abs(value)
```
