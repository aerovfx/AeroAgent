# Giải phương trình phức tạp: $5x^4 + 3y^5 - 627 = 0$

## Giới thiệu

Chào các bạn! Trong video này, chúng ta sẽ giải một phương trình phức tạp hơn:

$$
5x^4 + 3y^5 - 627 = 0
$$

Lần này chúng ta có:
- **Lũy thừa bậc cao**: $x^4$ và $y^5$
- **Hệ số**: 5 và 3
- **Hằng số**: 627

## Định nghĩa Phương trình trong Code

```python
def reward_function(x, y):
    equation_value = 5*(x**4) + 3*(y**5) - 627
    return 100 - abs(equation_value)
```

## Các bước giải

### Bước 1: Thiết lập khoảng tìm kiếm ban đầu

```python
x_min, x_max = 0, 10
y_min, y_max = 0, 10
step_size = 1
```

### Bước 2: Tạo States

```python
states = []
for x in np.arange(x_min, x_max + step_size, step_size):
    for y in np.arange(y_min, y_max + step_size, step_size):
        states.append((x, y))
```

### Bước 3: Định nghĩa Actions

```python
actions = [(-1, -1), (-1, 1), (1, -1), (1, 1)]
```

### Bước 4: Tính toán Reward

```python
R = {}
for state in states:
    x, y = state
    equation = 5*(x**4) + 3*(y**5) - 627
    reward = 100 - abs(equation)
    R[state] = {a: reward for a in actions}
```

### Bước 5: Value Iteration

```python
V = {s: 0 for s in states}
gamma = 0.9

for _ in range(100):
    V_new = {}
    for state in states:
        max_val = max(R[state][a] + gamma * V.get(next_state, 0) 
                     for a in actions)
        V_new[state] = max_val
    V = V_new
```

### Bước 6: Tìm nghiệm tối ưu

```python
sorted_items = sorted(V.items(), key=lambda x: x[1], reverse=True)
optimal = sorted_items[0][0]
print(f"x = {optimal[0]}, y = {optimal[1]}")
```

## Lưu ý quan trọng

⚠️ **Cẩn thận với lũy thừa âm**:
- Python không cho phép: `y**(-5)` = lỗi
- Giải pháp: Sử dụng `y**5` thay vì `1/(y**5)`

⚠️ **Số lớn**:
- Với lũy thừa cao, giá trị có thể rất lớn
- Cần chọn khoảng tìm kiếm phù hợp
