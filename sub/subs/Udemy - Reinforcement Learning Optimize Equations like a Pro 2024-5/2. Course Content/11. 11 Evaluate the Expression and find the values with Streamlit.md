## Cấu trúc Ứng dụng

### 1. Giao diện Streamlit

```python
import streamlit as st
import numpy as np

def main():
    st.title("Giải Phương trình với Học Tăng cường")
    
    # Ô nhập biểu thức
    expression = st.text_input("Nhập biểu thức toán học:", 
                               "3x + y^2 + z - 232")
    
    # Nút tính toán
    if st.button("Tính toán"):
        # Gọi hàm giải phương trình
        result = solve_equation(expression)
        
        # Hiển thị kết quả
        st.write(f"x = {result[0]}")
        st.write(f"y = {result[1]}")
        st.write(f"z = {result[2]}")

if __name__ == "__main__":
    main()
```

## Ví dụ Sử dụng

### Ví dụ 1: Phương trình đơn giản

**Nhập**: `3x + y^2 + z - 232 = 0`

**Kết quả**:
- Vòng 1: $x = 5, y = -5, z = -3$, kết quả = -2
- Vòng 2: $x = 5, y = -6, z = -2.5$, kết quả = -1.6
- Vòng 3: $x \approx 5, y \approx -6, z \approx -2.3$, kết quả ≈ 0.008
- Vòng cuối: Kết quả ≈ 0

### Ví dụ 2: Phương trình phức tạp

**Nhập**: `2x^3 + y/4 + z/2 - 527 = 0`

**Kết quả**:
- $x \approx 6.06$
- $y \approx 4$ 
- $z \approx 2.816$
- Thay vào: Kết quả ≈ 0.0003

### Ví dụ 3: Phương trình với lũy thừa

**Nhập**: `x + y^3 + z^2 - 78 = 0`

**Kết quả**:
- $x \approx 1$
- $y \approx 4$
- $z \approx 8$
- Thời gian: ~0.8 giây
