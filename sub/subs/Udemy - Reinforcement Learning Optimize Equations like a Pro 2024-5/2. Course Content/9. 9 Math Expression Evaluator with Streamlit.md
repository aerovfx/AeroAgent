# Sử dụng Streamlit để tạo Ứng dụng Tính toán Biểu thức Toán học

## Giới thiệu về Streamlit

**Streamlit** là một thư viện Python cho phép tạo ứng dụng web một cách nhanh chóng mà không cần biết HTML/CSS/JavaScript.

## Cài đặt

```bash
pip install streamlit
```

## Ví dụ đơn giản: Máy tính

### Code Python

```python
import streamlit as st
import ast

def evaluate_math_expression(expression):
    try:
        result = eval(expression)
        return result
    except:
        return "Lỗi: Biểu thức không hợp lệ"

def main():
    st.title("Máy tính biểu thức toán học")
    
    # Ô nhập liệu
    expression = st.text_input("Nhập biểu thức toán học:", "2 + 3")
    
    # Nút bấm
    if st.button("Tính toán"):
        result = evaluate_math_expression(expression)
        st.write(f"Kết quả: {result}")

if __name__ == "__main__":
    main()
```

### Chạy ứng dụng

```bash
streamlit run math_calculator.py
```

## Các thành phần Streamlit

### 1. Tiêu đề (Title)
```python
st.title("Tiêu đề")
```

### 2. Ô nhập liệu (Text Input)
```python
expression = st.text_input("Nhãn", "Giá trị mặc định")
```

### 3. Nút bấm (Button)
```python
if st.button("Nhãn nút"):
    # Code xử lý
```

### 4. Hiển thị kết quả
```python
st.write("Nội dung")
```
