# Giải phương trình 2 ẩn: $x^2 + y^2 - 50 = 0$

## Giới thiệu

Chào các bạn, trong video này chúng ta sẽ giải phương trình:

$$
x^2 + y^2 - 50 = 0
$$

Đây là lần đầu tiên chúng ta làm việc với **2 ẩn số**!

## Phân tích bài toán

- **2 ẩn số**: $x$ và $y$
- **States**: Bây giờ là các **cặp tuple** $(x, y)$
- **Actions**: Cần **4 hành động** thay vì 2

## Tạo States cho 2 ẩn số

```python
x_min, x_max = 0, 10
y_min, y_max = 0, 10
step_size = 1

states = []
for x in np.arange(x_min, x_max + step_size, step_size):
    for y in np.arange(y_min, y_max + step_size, step_size):
        states.append((x, y))
```

**Ví dụ states**:
- (0, 0), (0, 1), (0, 2), ...
- (1, 0), (1, 1), (1, 2), ...
- ...
- (10, 10)

## Định nghĩa Actions

Với 2 biến, chúng ta cần 4 actions:

| Action | Thay đổi x | Thay đổi y |
|--------|------------|------------|
| (-1, -1) | x - 1 | y - 1 |
| (-1, +1) | x - 1 | y + 1 |
| (+1, -1) | x + 1 | y - 1 |
| (+1, +1) | x + 1 | y + 1 |

```python
actions = [(-1, -1), (-1, 1), (1, -1), (1, 1)]
```

## Transition Probabilities

```python
P = {}
for state in states:
    x, y = state
    P[state] = {}
    for action in actions:
        dx, dy = action
        next_x = x + dx
        next_y = y + dy
        next_state = (next_x, next_y)
        
        if next_state in states:
            P[state][action] = {(next_state, 1.0)}
        else:
            P[state][action] = {(state, 1.0)}
```

## Reward Function

```python
R = {}
for state in states:
    x, y = state
    R[state] = {}
    for action in actions:
        reward = 100 - abs(x**2 + y**2 - 50)
        R[state][action] = reward
```

**Công thức**:

$$
R = 100 - |x^2 + y^2 - 50|
$$

- Khi $x^2 + y^2 = 50$: Phần thưởng tối đa = 100
- Nghiệm đúng: $x = 5, y = 5$ vì $5^2 + 5^2 = 25 + 25 = 50$

## Value Iteration

```python
V = {s: 0 for s in states}
gamma = 0.9

for iteration in range(100):
    for state in states:
        max_value = float('-inf')
        for action in actions:
            # Tính toán giá trị
            value = R[state][action] + gamma * V[next_state]
            max_value = max(max_value, value)
        V[state] = max_value
```
