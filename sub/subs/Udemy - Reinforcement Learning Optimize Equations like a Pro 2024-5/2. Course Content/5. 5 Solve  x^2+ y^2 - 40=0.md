# Giải phương trình $x^2 + y^2 - 40 = 0$ với Co giãn Khoảng tìm kiếm

## Giới thiệu

Trong video trước, chúng ta đã giải $x^2 + y^2 = 50$ và tìm được $x = 5, y = 5$. Trong video này, chúng ta sẽ giải:

$$
x^2 + y^2 - 40 = 0
$$

## Vấn đề

Với phương trình $x^2 + y^2 = 40$:
- Không có nghiệm nguyên đơn giản
- Cần tìm nghiệm gần đúng

### Kết quả vòng lặp đầu tiên

Với step size = 1:
- Kết quả: $x = 5, y = 4$
- Kiểm tra: $5^2 + 4^2 - 40 = 25 + 16 - 40 = 1$ ❌

## Phương pháp Co giãn Khoảng

### Vòng lặp 1
- x_min = 4, x_max = 6 (5 - 1, 5 + 1)
- y_min = 3, y_max = 5 (4 - 1, 4 + 1)
- step_size = 0.1

**Kết quả**: $x = 4.9, y = 4.0$
- Kiểm tra: $4.9^2 + 4^2 - 40 = 24.01 + 16 - 40 = 0.01$ ✓

### Vòng lặp 2
- x_min = 4.0, x_max = 5.0
- y_min = 3.5, y_max = 4.5
- step_size = 0.01

**Kết quả**: $x = 4.05, y = 4.85$
- Kiểm tra: $4.05^2 + 4.85^2 - 40 \approx 0.006$

### Vòng lặp 3
- x_min = 4.0, x_max = 4.2
- y_min = 4.7, y_max = 4.9
- step_size = 0.001

**Kết quả**: $x \approx 4.0695, y \approx 4.8413$
- Kiểm tra: Gần như bằng 0

## Code mẫu

```python
for i in range(5):  # 5 vòng lặp
    # Tạo states với khoảng hiện tại
    states = create_states(x_min, x_max, y_min, y_max, step_size)
    
    # Tính toán value iteration
    V = value_iteration(states, actions, R, gamma)
    
    # Tìm nghiệm tối ưu
    sorted_items = sorted(V.items(), key=lambda x: x[1], reverse=True)
    optimal = sorted_items[0][0]
    
    # Cập nhật khoảng tìm kiếm
    x_min = optimal[0] - step_size
    x_max = optimal[0] + step_size
    y_min = optimal[1] - step_size
    y_max = optimal[1] + step_size
    
    # Giảm step size
    step_size = step_size / 10
```
