# Giải phương trình $x^2 - 25 = 0$ bằng Học Tăng cường

## Giới thiệu

Chào các bạn, chào mừng trở lại!

Trong video này, chúng ta sẽ xây dựng một dự án để tìm nghiệm cho phương trình sau:

$$
x^2 - 25 = 0
$$

Chúng ta đều biết rằng $x = 5$ là nghiệm đúng của phương trình này. Tuy nhiên, điều quan trọng là chúng ta cần học cách hoạt động của **học tăng cường** (Reinforcement Learning) thông qua dự án này.

## Cấu trúc States (Trạng thái)

Trong học tăng cường, đầu tiên chúng ta cần định nghĩa các **states** (trạng thái):

### Định nghĩa khoảng giá trị

- **Minimum x**: 0
- **Maximum x**: 10
- **Step size** (kích thước bước): 1

Sử dụng NumPy để tạo mảng:

```python
x = np.arange(x_min, x_max + step_size, step_size)
```

**Lưu ý**: Khi sử dụng `np.arange()`, giá trị maximum không bao gồm, do đó cần cộng thêm `step_size`.

### Tạo States

Với step size = 1, các states sẽ là: 0, 1, 2, 3, ..., 10

Với step size = 0.1, các states sẽ tăng dần với bước 0.1.

## Actions (Hành động)

Trong các bài toán game như rắn săn mồi, agent di chuyển lên/xuống/trái/phải. Nhưng với bài toán toán học này, states là các con số, do đó:

- **Action -1**: Giảm giá trị xuống 1 đơn vị
- **Action +1**: Tăng giá trị lên 1 đơn vị

## Transition Probabilities (Xác suất chuyển đổi)

Chúng ta cần định nghĩa ma trận chuyển đổi $P(s'|s, a)$:

```python
P = {}
for x in states:
    P[x] = {}
    for a in actions:
        next_x = x + a
        if next_x in states:
            P[x][a] = {(next_x, 1.0)}  # 100% đến next_x
        else:
            P[x][a] = {(x, 1.0)}  # 100% ở lại state hiện tại
```

**Giải thích**: 
- Nếu thực hiện action mà next_x nằm trong danh sách states → di chuyển đến đó với xác suất 100%
- Nếu next_x không nằm trong danh sách → ở lại tại state hiện tại

## Reward Function (Hàm phần thưởng)

Đây là phần quan trọng nhất. Agent cần được thưởng khi tiến gần đến nghiệm đúng.

```python
R = {}
for x in states:
    R[x] = {}
    for a in actions:
        next_x = x + a
        reward = 100 - abs(x**2 - 25)
        R[x][a] = reward
```

**Công thức**:

$$
R = 100 - |x^2 - 25|
$$

- Khi $x = 5$: $R = 100 - |25 - 25| = 100$ (phần thưởng cao nhất)
- Khi $x = 0$: $R = 100 - 25 = 75$

## Value Function (Hàm giá trị)

Sử dụng **Value Iteration** để tính toán:

```python
V = {s: 0 for s in states}
gamma = 0.9

for iteration in range(100):
    for x in states:
        max_value = float('-inf')
        for a in actions:
            next_x = x + a
            if next_x in states:
                value = R[x][a] + gamma * V[next_x]
                max_value = max(max_value, value)
        V[x] = max_value
```

**Công thức Bellman**:

$$
V(s) = \max_a \left[ R(s, a) + \gamma \sum_{s'} P(s'|s, a) V(s') \right]
$$

Trong đó:
- $\gamma = 0.9$ là hệ số chiết khấu (discount factor)
- $R(s, a)$ là phần thưởng
- $P(s'|s, a)$ là xác suất chuyển đổi

## Kết quả

Sau khi chạy thuật toán:

| State (x) | Giá trị V |
|-----------|-----------|
| 0 | 893 |
| 1 | 909 |
| 2 | ... |
| 5 | **957** (cao nhất) |

**Đáp án đúng**: $x = 5$

Giá trị cao nhất tại state 5, có nghĩa là đây là giải pháp tối ưu!
