So optical character recognition is a method of converting the text present in images to a machine readable

format, machine readable format simply refers to the text that the machine can understand or the text

that you can select, edit, search, etc., etc..

So let's take an example to understand what this actually means.

So suppose you are given this image, clearly as we can see that there is some text present in this

image, but for a computer, this is nothing but an array of pixel values as shown, the computer doesn't

know whether this image contains text, car, bus, etc., etc. So this text is not in a machine readable

format.

Also, we can't select, edit or do any further processing on this text. Now to change this text to a machine

readable format,

We use OCR.

So what the system will do is digitize this printed text.

That is, take this image as an input and output a text file containing all the text present in the

image.

Now you can do anything with this text that you want.

So now you know coarsely what an OCR system is. Now let's try to understand why you should invest your time in learning

this.

For this, let's take a few real life examples where OCR has made our life easy.

You already might have encountered these in your day to day life, but might not have thought about

how these work.

So let's quickly go through some of its applications, so one of the most prominent application of OCR

is automatic data entry, most of you might know that earlier people used to manually enter the details

from business documents, invoices, receipts, etc., etc. This would take a lot of effort, time and

cost.

But now with the help of OCR, most of these tasks are automated.

So instead of manually entering the details, now the person's task is just reduced to validating the

OCR results only.

This reduces manpower, time and cost and improves the employee productivity and profit.

For instance, in banks, instead of manually entering the cheque details, the cheque is first scanned

and then the OCR extracts all the useful information, such as account number, amount, etc,

etc..

Similarly, at airports, your passport information is extracted from the machine readable zone or MRZ

leading to the faster processing.

I hope you must have seen this when you visit airport or bank.

Now, another important application that you might be familiar with is number-plate recognition.

Almost everyone might have seen or heard about this application. OCR is used to recognize the vehicle

number plate, which can then be used for vehicle tracking, the toll collection, etc., etc..

Now, another application is in self-driving cars.

Now, most of you might be thinking of how and where the OCR is used in self-driving cars.

The answer is in recognizing the traffic signs.

The autonomous car uses OCR to organize the traffic signs and thus take actions accordingly.

Without this, the self-driving car will pose a risk for both pedestrians and other vehicles on the

road.

I hope you understood this.

Now, another application is in book scanning, so OCR is widely used in digitizing scanned documents,

for instance, you might have heard about Project Gutenberg that tries to digitize and archive cultural

works.

Most of these items are available free of cost.

Similarly, Google Books scans books, converts them to text using OCR and stores them in the digital

database.

OCR has also proved to be a great asset for visually impaired persons in this we can use OCR to extract

the text from any document and then use text-to-speech to read the extracted text.

This approach was first used around 1976 and the work is still going on.

So these are just a few of many OCR applications that you might encounter in your day to day life

from these applications, we can see that because of OCR, most of the work has now been automated,

which helps in saving time, money, manpower, etc., etc..
