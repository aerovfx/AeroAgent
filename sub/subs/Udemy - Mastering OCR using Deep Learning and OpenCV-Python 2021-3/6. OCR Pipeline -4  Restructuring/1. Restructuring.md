# 1. Restructuring

---

So till now, we have covered the image preprocessing, text detection and the text recognition steps

in detail.

In this video, let's discuss the last pipeline component that is restructuring in detail. So let's

get started.

So given an input image, we have the recognized text along with it's position in the input image.

This text we obtained from the CRNN model and these bounding box coordinates we obtained from the EAST model.

I hope you remember this.

Now it's time to restructure this text.

So restructuring simply means placing the text similar to how it was in the original image.

So this can be done simply by iterating over these bounding box coordinates and placing the recognized

text at that location.

See how after restructuring both the restructured text and the original image looks almost similar.

Now, most of you might be wondering, why do we need to do this or what's the use of this restructuring?

So let's take a simple example to understand this.

Suppose you have two text files, one containing the restructured text and other not. And let's say

we want to extract the bill number from both of these.

So for the restructured one, we can directly tell the computer to extract the text following "BLL NO:"

so this can be done easily using the regular expression or any NLP technique.

But what about the other case where we have not restructured the text. In this first we need to find

the coordinates corresponding to the text "BLL NO:".

Once we have obtained the coordinates, we then iterate over all the coordinates, finding the coordinates

that lie in the same line and then extract the corresponding word.

So clearly, this would take a lot of effort as compared to when we have restructured the text, so this

is how restructuring the text saves us from a lot of extra effort while doing information extraction.
