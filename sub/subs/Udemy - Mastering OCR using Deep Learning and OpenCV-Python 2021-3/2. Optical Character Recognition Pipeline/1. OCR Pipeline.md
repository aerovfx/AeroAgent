# 1. OCR Pipeline

---

So in this video, let's understand the general pipeline used by most of the OCR systems. So given

an input image, we first need to pre-process it.

So if you have ever done any computer vision task, such as image classification or object detection,

then you must know how important this step is.

Preprocessing simply means making the image suitable for the further steps.

So in this, we try to remove any type of deformity present in the image such as noise etc.

So after preprocessing, the next step is text detection.

So in this, we try to find out the regions in the image where the text can be present.

For instance, see this image where the detected text regions are shown by the green color bounding boxes.

After detecting the text regions, the next task is to recognize what text is present in those regions.

We call this as text recognition.

Finally, we need to restructure the recognized text so that it looks almost similar to that of the original

image.

So this competes the general OCR pipeline.

As you might have noticed, that this is almost similar to how we humans recognize the text. for instance,

given any image containing text, we first tried to locate the text and then recognize it.

This is done so fast by the eyes and brain that we hardly even notice it.

Now, let's take this image as an example and try to visualize what happens at each component. Here

I have intentionally returned the image and added some salt and pepper noise to it.

So in the preprocessing step, this image is corrected for both noise and rotation as shown on the right.

This corrected image is then passed to the text detection model that outputs the detected text regions

as shown by the green color bounding boxes.

These detected regions are then passed one by one to the text recognition model that outputs the text

along with the bonding box coordinates as shown.

Finally, we need to restructure the recognized text, this can be done simply by iterating over these

coordinates and placing the text at that location.

See how after restructuring, both the restructured and the original image looks almost similar.

Now, you may ask, why do we need restructuring?

This is something we will discuss later.

For now, just remember that restructuring makes the output look similar to that of the original image.

So this is generally how the OCR system work.

Now, you can do anything with this restructured image, you can edit it, you can search it or even

translate it.
