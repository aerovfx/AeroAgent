In this video, let's discuss different noise removal techniques in detail.

So let's first discuss what is noise in the context of images.

So noise simply refers to any random variation of brightness or color information in the images.

For instance, check out this image that is corrupted with noise as is clearly visible.

Now, what will happen if you don't remove the noise?

So if you don't remove the noise, then there is a maximum possibility that you will get faulty results

in the further steps.

And this in turn will really hamper the OCR accuracy.

So it's always better to denoise the image before passing it to any system.

Now images can be corrupted with different types of noises such as salt and pepper noise, Gaussian noise,

speckled noise, etc., etc. So depending on the type of noise, different noise removal techniques

exist.

For instance, for salt and pepper noise, we use median filtering while for the Gaussian noise

Gaussian blurring technique is used.

So in order to remove the noise, you first need to identify what type of noise is present and then

apply suitable denoising technique.

As such, there is no general noise removal technique that works for all types of noises.

So carefully select the noise technique according to the type of noise present.
