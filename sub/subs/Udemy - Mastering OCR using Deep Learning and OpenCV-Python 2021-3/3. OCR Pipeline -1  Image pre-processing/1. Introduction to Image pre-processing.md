# 1. Introduction to Image pre-processing

---

So in the previous video, we just had an overview of the general OCR pipeline. Now in this video,

let's discuss the first pipeline component that is image prepossessing in detail.

So, as we have already discussed, the prepossessing simply means making the image suitable for further

steps.

So in this, we try to remove any type of deformity present in the image such as noise, skewness, etc..

Now what will happen if I don't pre-process the image?

So obviously there is a maximum possibility that you may get faulty results in the further steps.

So it's always better to be pre-process the image before feeding it to other systems.

And the following videos, we will be covering some of the most commonly used image pre-processing techniques in OCR.

We will be covering image normalization, resizing, noise removal, skew correction, etc., etc.,

as shown here.

All these techniques will come handy when we will discuss the text detection and the recognition step. Now

for the implementation

we will be mainly using the OpenCV libraries.
