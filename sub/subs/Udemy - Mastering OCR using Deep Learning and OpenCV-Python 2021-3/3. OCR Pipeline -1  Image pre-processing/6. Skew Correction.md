In this video, let's discuss the Skew correction technique in detail.

So while performing OCR, most of the times you will encounter the images that are skewed or rotated

as shown.

So in order to get good OCR results, you first need to deskew them or correct them for rotation.

So this process of deskewing or straightening the rotated images is known as skew correction.

As such, there is no single skew correction technique that works for all types of images.

But the basic idea behind all these techniques is quite similar.

That is we first need to detect any feature from which we can calculate the skew angle.

For instance, for this image, a good feature can be this box as shown by the blue color, while

for this image

a good feature can either be a line or a text block as shown.

From these features, we can easily calculate the skew angle theta.

So once we have obtained the skew angle, then we can simply re-rotate the image to that angle.

So this is the basic idea behind most of the skew correction techniques.

Now, let's take this image as an example to understand the skew correction technique.

So, as discussed, we first need to detect any feature from which we can calculate the skew angle.

So for this image, a good feature can be this box as shown by the blue color.

So first, we need to detect this box.

This can be easily done using OpenCV contours, that is, for this image

we first need to find all the contours and then pick out the one with the maximum area.

So once this box is detected, we then need to find the skew angle.

This can be done using OpenCV cv2.minAreaRect function that fits the minimum area rotated

rectangle to this contour.

This function returns the skew angle along with other values.

One thing to remember is that this function only works for minus forty five to forty five degree rotation.

So once we obtain the skew angle, we then simply re-rotate the image to obtain the final deskewed image as
