# 1. Congratulations

---

Hi, and congratulations on completing this first course in this OCR series.

I hope you now know what is OCR, how it works and how to apply this on real life applications.

In this course, we try to keep the things simple.

For instance, we used pre train models for EAST, CTPN.

We only implemented EAST for the horizontal text case, etc., etc..

This is done mainly to make you feel comfortable with these algorithms now, in the next course, we

will move a step further.

We will try to implement everything from scratch using

tensorflow.

We will mainly focus on the unstructured text or text in the wild and also we will learn how to combine text

detection and the text recognition steps to build our own custom end-to-end OCR system.

Again, congratulations, and I hope to see you in the next course.

Thanks.
