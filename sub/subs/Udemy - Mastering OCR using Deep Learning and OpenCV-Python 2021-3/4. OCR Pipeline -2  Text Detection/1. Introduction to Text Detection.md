In the previous video, we discussed different preprocessing techniques such as noise removal, skew

correction, etc. The main objective of this preprocessing step was to make the image suitable for the next

pipeline components, such as text detection and recognition.

Now, in this video, let's understand the text detection step in detail.

So text detection simply means finding the regions in the image where text can be present. For instance, see

this image where the green-colored bounding boxes are drawn around the detected text regions.

While performing text detection, you may encounter two types of images, one where we have structured

text and the other one where we have unstructured text. Now let's understand what the structured and

unstructured text means.

So let's start with the structured text.

So this refers to the images that have a clean or uniform background with a regular font.

The text is mostly dense with the proper row structure.

Most of these images will have a uniform text color, for instance, check out this image as shown on

the right.

While for the unstructured case, the images will have sparse text on a complex background.

The text can have different color, font, size, orientations, and can be present anywhere in the image.

For instance, check out this image as shown on the right.

Performing text detection on these images is also known as scene text detection.

Obviously, the unstructured case is more challenging as compared to this structured case, and that's

why this is an active research topic in computer vision.

Now, while performing text detection, you have three options, either you do character by character

detection or word by word detection or line-by-line detection.

Nowadays, we mostly prefer doing word by word, line by line detection.

This is mostly because the character detection is generally slow and is somewhat more challenging as

compared to the other two methods.

Now, mostly, the text detection methods can be broadly classified into two categories.

Conventional methods and the deep learning based methods. The conventional methods rely on manually

designed features, while in the deep learning based methods, features are learned from the training data.

These are generally better than the conventional methods in terms of both accuracy and adaptability

in the challenging scenarios.

The deep learning based methods can be further classified into two types, the methods with multi-step

pipeline and the methods with simplified pipeline.

To understand these, take a look at this image that shows the pipeline of several text detection algorithms
