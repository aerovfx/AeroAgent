This mainly consists of two stages.

First, the input image is fed to a multi-channel, fully convolutional network that directly produces

Now, before discussing this network architecture in detail, let's first discuss the motivation behind

choosing this architecture for the EAST algorithm.

As we all know that the size of the text can vary tremendously from image to image. We can have any

size text, we can have large text, we can have small text or even medium-sized text also.

So for detecting large words, we require features from the deep layers, while for the small word regions,

information from the shallow layers is sufficient.

Thus, in order to detect different sized words, we should build a network that uses features from the different

levels of the network and is computationally efficient.

So one thing that comes to mind is to use a U-shape network, as this can both utilize different levels

of features and keeps a small computation cost.

So this was the motivation for selecting a U-shape network for the EAST algorithm.

So to form the final results after prediction, first, the geometry map is converted back to the bounding

Then we apply thresholding based on the score map to remove some low confidence boxes and finally the

The EAST algorithm uses a locality aware non-max suppression that runs faster than the standard non-max

suppression.

So let's understand the locality aware nms in detail.

In this, we first sort the bounding boxes and start from the topmost.

Then we take the next box in the row and find the intersection over union with the previous box.

If the intersection over union is greater than the set threshold, we merge these two boxes together

by taking the weighted average by score, otherwise we keep it as it is.

We keep repeating these two steps until all the boxes are iterated.

At last, we apply the standard nms on the remaining boxes to yield the final output text boxes.

So this is how the locality aware nms works.
