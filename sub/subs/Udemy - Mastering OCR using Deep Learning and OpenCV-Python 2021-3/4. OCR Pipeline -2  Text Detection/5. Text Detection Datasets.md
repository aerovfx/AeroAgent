# 5. Text Detection Datasets

---

In the previous videos, we mostly covered the OCR text detection step. As you might remember, we discussed

that the data for the text detection task generally consist of images and the corresponding text files.

These text files generally contain the coordinates for words present in the image as shown.

But we didn't discuss much about the text detection datasets.

So in this video, let's explore them further.

So let's first discuss some of the open-source datasets that are available. Here instead of individually

discussing each of these datasets, I have this table that shows their comparison.

Here, the first column contains the dataset name while the second and the third column denotes the number of

images and the total number of words present in the dataset.

The last three columns denote the text orientation, that is whether the text is horizontal, curved or

multi-oriented.

So depending upon your problem, you need to choose the dataset.

For instance, if you want to detect the curved text, then training your model on these three data sets

will not help.

So choose the data set according to your application or the problem statement.

When speaking about the data sets, the text detection task is not so rich. What I meant by that is there

are only a limited number of text detection datasets that are available.

So we may need to manually create data in order to train or further fine-tune our text detection model.

At first glance, this might look like a tedious task, but thanks to annotation tools using which we

can quickly and accurately build the ground truth for any task. There are several annotation tools available

such as labelImg, Coco-annotator, etc., etc. All these tools are very easy to use.

For instance, here is a screenshot of the labelImg annotation tool. In this,

For each image, you just need to draw the bounding boxes and the coordinates will be automatically

saved in the XML format.

So this is how simple it is.

So if you ever want to create your own dataset, always use the annotation tools. Thanks.
