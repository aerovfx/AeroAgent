So you might think that CTC uses some cool trick to align the output with the per time-step predictions.

But rather it uses a very simple idea.

So what CTC does is, it tries out all the possible combinations of the actual text that can occur in

the per timestep predictions.

And then from all these combinations, CTC picks only those that lead to the actual text for calculating

the loss.

So this is how simple the CTC algorithm is.
