# 2. CRNN model and Intuition behind CTC

---

In this video, we will discuss the intuition behind the CTC algorithm. As we have already discussed,

that in text recognition, we are given a segmented image and our task is to recognize what text is

written in that segment.

Thus, for the text recognition problem, the input is an image, well, the output is the text.

So to solve this problem, we need to develop a model that takes image as an input and outputs

the recognized text.

Since in deep learning, we know that the convolutional neural networks are good in handling image data.

While for the sequential such as text, recurrent neural network or RNNs are preferred.

So for the text recognition problem and obvious choice that comes to our mind is to use a combination

of convolutional neural networks with recurrent neural networks.

So let's understand how to combine CNN and RNN together for the text recognition problem.

So here is one such network architecture. In this, first the input image is fed through a number of convolutional

layers to extract the feature map.

This feature map is then divided into a sequence of feature vectors as shown by the blue color.

Here each feature vector is generated by dividing the feature map into columns of single pixel width.

Now, a question might come to your mind that why we are  dividing the feature map by columns. So I hope you

remember the receptive field concept from the CTPN video.

So from the receptive field point of view, each of the feature vector corresponds to a rectangular region

in the input image and all these rectangular regions are ordered from left to right, as shown by the

image.

Thus each feature vector can be considered as the image descriptor for that rectangular region in the

input image.

These feature vectors are then fed to a bidirectional LSTM.

We are using an LSTM so as to solve the problem of vanishing gradient and a bidirectional one so that

the context information from the entire image can be used in making the decision at each time step.

Since at each time step, the input to RNN is a sequence of feature vectors, and these feature vectors

sometimes may not contain the complete character.

For instance, these two feature vectors contains some part of the character 'S'. Thus in the RNN,

we may get repeated characters as output as shown by the red box in this image.

Now, here comes the problem, as we have already discussed, that the training data consists of images

and the corresponding text.

Thus, we only know the final outputs and we don't know the per timestep predictions, and without knowing

these outputs at each time step, we can't train the network.

So the main question that comes up is how can we train this network?

So one thing that you can do is create a rule like one character corresponds to some fixed time steps.

So for this image that contains the text 'STATE', if we have 10 time steps, we can repeat each

character twice and then train the network.

But this rule can be easily violated as the image can have different fonts, writing stains, etc..

Another solution can be to manually annotate the data corresponding to each timestamp as shown by the

image on the right.

The problem with the solution is that this will be very time consuming for a reasonably sized dataset.

So is there any way to train the network only with the output labels without knowing the per time step prediction?

And the answer to this question is yes, by using the connectionist temporal classification or CTC

approach.

With CTC, we need not to worry about the alignment's or the per time step predictions. CTC takes care

of all the alignments and now we can train the network only using the final outputs.
