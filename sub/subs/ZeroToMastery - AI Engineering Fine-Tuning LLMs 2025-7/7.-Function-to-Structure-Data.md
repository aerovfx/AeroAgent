# Hàm để Định dạng Dữ liệu

## Giới thiệu

Bây giờ chúng ta sẽ xây dựng một hàm để tổng hợp dữ liệu vào định dạng chuẩn cho fine-tuning.

## Định nghĩa System Prompt

System prompt xác định vai trò và phong cách viết của assistant:

```python
system_message = """Bạn là Diego, người tạo nội dung về Data và AI.
Bạn là chuyên gia viết bài đăng LinkedIn.
Bạn viết các bài đăng mạnh mẽ, hấp dẫn, không bao phòng.
Sử dụng từ vựng đơn giản và không trang trọng.
Bắt đầu bài đăng bằng một câu kích thích.
Sau đó các đoạn văn có độ dài một câu."""
```

## Hàm prepare_data

```python
def prepare_data(system, prompt, output):
    messages = []
    messages.append({"role": "system", "content": system})
    messages.append({"role": "user", "content": prompt})
    messages.append({"role": "assistant", "content": output})
    return {"messages": messages}
```

**Giải thích:**
- `system`: System prompt (vai trò của assistant)
- `prompt`: User prompt (đầu vào/câu hỏi)
- `output`: Assistant response (nội dung bài đăng LinkedIn)

## Áp dụng cho Training và Validation Data

### Cho training data:

```python
train_data = []
for post, prompt in zip(posts, generated_prompts):
    train_data.append(prepare_data(system_message, prompt, post['content']))
```

### Cho validation data (test set):

```python
test_data = []
for post, prompt in zip(test_posts, test_prompts):
    test_data.append(prepare_data(system_message, prompt, post['content']))
```

## Kiểm tra dữ liệu

Sau khi chạy, chúng ta có thể kiểm tra:

```python
train_data[0]
```

**Kết quả sẽ có dạng:**
```json
{
  "messages": [
    {"role": "system", "content": "Bạn là Diego, người tạo nội dung..."},
    {"role": "user", "content": "Viết bài đăng LinkedIn về..."},
    {"role": "assistant", "content": "Nội dung bài đăng..."}
  ]
}
```

## Tóm tắt

Bây giờ dữ liệu của chúng ta đã sẵn sàng! Mỗi entry bao gồm:
- **System message:** Định nghĩa vai trò và phong cách
- **User message:** Prompt đầu vào
- **Assistant message:** Nội dung output mong đợi

**Bước tiếp theo:**
Chúng ta cần đưa dữ liệu này vào định dạng JSONL để có thể tải lên OpenAI.
