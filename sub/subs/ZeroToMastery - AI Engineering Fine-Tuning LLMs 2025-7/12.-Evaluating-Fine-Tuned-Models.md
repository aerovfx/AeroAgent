# Đánh giá các Model Fine-tuned

## Giới thiệu

Chào mừng quay lại! Trong video này, chúng ta sẽ tìm hiểu sâu về đánh giá cho các model fine-tuned. Sau khi đầu tư nhiều công sức, bạn muốn đảm bảo model tùy chỉnh đáp ứng mục tiêu và hoạt động như mong đợi.

## Tại sao Đánh giá quan trọng?

Đánh giá giúp chúng ta xác định:
- Model có cung cấp những gì chúng ta muốn và cần không?
- Quá trình huấn luyện có thành công không?
- Model có phù hợp cho triển khai thực tế không?

**Điều quan trọng:** Không chỉ là về độ chính xác. Đây là về:
- **Relevance** (Liên quan)
- **Consistency** (Nhất quán)
- **Quality** (Chất lượng)

## Các loại Metrics

### 1. Quantitative Metrics (Metrics định lượng)

Bao gồm các phép đo số như:
- **Training Loss**: Đo mô hình học tốt bao nhiêu trong quá trình fine-tuning
- **Validation Loss**: Đo mô hình generalize tốt bao nhiêu với dữ liệu unseen

**Mục tiêu:**
- Training loss giảm dần theo thời gian
- Validation loss gần với training loss

**Các vấn đề cần tránh:**

| Tình huống | Nguyên nhân | Giải pháp |
|-----------|-------------|------------|
| Validation loss = 0 | Data leakage | Kiểm tra train/val separation |
| Val loss >> Train loss | Overfitting | Thêm dữ liệu đa dạng |

### 2. Qualitative Metrics (Metrics định tính)

Liên quan đến phân tích chất lượng phản hồi của model:
- Giọng điều có phù hợp không?
- Output có align với kỳ vọng không?

## Quy trình Đánh giá Chi tiết

### Bước 1: Tạo Test Prompts

Tạo các prompt thực tế cho các kịch bản khác nhau:

```python
test_prompts = [
    {
        "system": "Bạn là người viết LinkedIn chuyên nghiệp...",
        "user": "Viết bài về tính năng AI analytics mới"
    },
    {
        "system": "Bạn là người viết LinkedIn chuyên nghiệp...",
        "user": "Viết bài về khóa học fine-tuning GPT"
    }
]
```

### Bước 2: Test với Fine-tuned Model

```python
response = client.chat.completions.create(
    model=fine_tuned_model_id,
    messages=[
        {"role": "system", "content": test_prompt["system"]},
        {"role": "user", "content": test_prompt["user"]}
    ],
    temperature=0.7
)
```

### Bước 3: Đánh giá Output

**Các câu hỏi cần trả lời:**

1. **Giọng điều có phù hợp không?**
   - Cùng phong cách với dữ liệu training?
   - Formal/informal đúng mức?

2. **Thông tin có chính xác không?**
   - Sử dụng đúng prompt?
   - Không đi lệch hướng?

3. **Style có phù hợp brand không?**
   - Nhất quán với yêu cầu?

### Bước 4: Điều chỉnh Temperature

- **Creative tasks:** temperature = 1.0-1.2
- **Structured tasks:** temperature = 0

## Cải thiện Iterative

### Thêm dữ liệu

- Thêm nhiều ví dụ hơn
- Đảm bảo đa dạng
- Loại bỏ examples chất lượng kém

### Điều chỉnh Prompts

- System prompt có phản ánh điều bạn muốn không?
- User prompt đủ rõ ràng?

### Chạy lại Fine-tuning

```python
# Sau khi cải thiện dữ liệu
response = client.fine_tuning.jobs.create(
    training_file=new_train_file_id,
    validation_file=new_validation_file_id,
    model="gpt-4o-2024-08-06",
    suffix="linkedin-v2"
)
```

## Checklist Triển khai

Trước khi đưa vào production:

- [ ] Chất lượng output nhất quán
- [ ] Giọng điều đáp ứng yêu cầu
- [ ] Training và validation loss đủ thấp
- [ ] Test thực tế thành công
- [ ] Generalize tốt với dữ liệu mới

## Kết luận

Đánh giá model fine-tuned bao gồm:
1. ✅ Hiểu tại sao quan trọng
2. ✅ Sử dụng quantitative metrics (losses)
3. ✅ Thực hiện qualitative analysis
4. ✅ Cải thiện iterative

**Lưu ý:** Thành công không chỉ là model hoạt động tốt trên ví dụ đã cho, mà còn phải generalize hiệu quả với prompts mới và unseen.
