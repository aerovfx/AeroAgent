# Tạo các file JSONL

## Giới thiệu

Chào mừng quay lại! Bây giờ chúng ta đã có dữ liệu trong danh sách, chúng ta sẽ xây dựng một hàm để tạo các file JSONL - đây là định dạng đầu vào mà OpenAI yêu cầu.

## Định dạng JSONL

**JSONL (JSON Lines)** là định dạng file văn bản trong đó mỗi dòng là một đối tượng JSON hợp lệ riêng biệt.

**Đặc điểm:**
- Mỗi dòng là một JSON object hoàn chỉnh
- Dễ đọc và xử lý
- OpenAI Fine-tuning API chỉ hỗ trợ định dạng này
- Giới hạn: file lên đến 2 triệu tokens

## Hàm tạo JSONL

```python
def create_jsonl(data_list, file_name):
    with open(file_name, 'w') as file:
        for item in data_list:
            json_line = json.dumps(item)
            file.write(json_line + '\n')
```

**Giải thích:**
- `json.dumps()`: Chuyển dictionary thành chuỗi JSON
- Mỗi object JSON được viết trên một dòng riêng biệt

## Tạo Training và Validation Files

```python
# Training data
create_jsonl(train_data, 'train.jsonl')

# Validation data
create_jsonl(test_data, 'test.jsonl')
```

## Xem trước nội dung JSONL

```python
# Xem 5 dòng đầu tiên
with open('train.jsonl', 'r') as f:
    for i, line in enumerate(f):
        if i >= 5:
            break
        print(line[:500])  # Chỉ in 500 ký tự đầu
```

**Đầu ra mẫu:**
```json
{"messages": [{"role": "system", "content": "Bạn là Diego..."}, {"role": "user", "content": "Viết bài đăng LinkedIn..."}, {"role": "assistant", "content": "Nội dung bài đăng..."}]}
```

**Đặc điểm quan sát được:**
- System prompt luôn giống nhau cho tất cả các dòng
- User prompts khác nhau (chủ đề khác nhau)
- Assistant responses khác nhau theo từng bài đăng
