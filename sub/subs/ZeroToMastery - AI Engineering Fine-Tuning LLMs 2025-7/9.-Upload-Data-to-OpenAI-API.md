# Tải dữ liệu lên OpenAI API

## Giới thiệu

Chào mừng quay lại! Bây giờ chúng ta sẽ tải các file JSONL lên OpenAI API.

## Hàm Upload File

```python
def upload_file(file_name, purpose):
    with open(file_name, "rb") as file:
        response = client.files.create(
            file=file,
            purpose=purpose
        )
    return response.id
```

**Giải thích:**
- `file_name`: Tên file cần tải lên
- `purpose`: Mục đích sử dụng - trong trường hợp này là "fine-tune"
- `response.id`: File ID được trả về từ OpenAI

## Thực hiện Upload

```python
# Upload training file
train_file_id = upload_file("train.jsonl", "fine-tune")
print("Training file ID:", train_file_id)

# Upload validation file
validation_file_id = upload_file("test.jsonl", "fine-tune")
print("Validation file ID:", validation_file_id)
```

## Kiểm tra trên OpenAI Dashboard

Sau khi upload thành công, bạn có thể kiểm tra trong OpenAI Playground:
- Vào phần **Storage**
- Bạn sẽ thấy cả hai file: `train.jsonl` và `test.jsonl`

## File IDs

Mỗi file sau khi upload sẽ có một **file_id** riêng biệt:
- `train_file_id`: Sử dụng để huấn luyện
- `validation_file_id`: Sử dụng để validate trong quá trình fine-tuning

**Quan trọng:** Lưu lại các file IDs này vì bạn sẽ cần chúng để tạo fine-tuning job!
