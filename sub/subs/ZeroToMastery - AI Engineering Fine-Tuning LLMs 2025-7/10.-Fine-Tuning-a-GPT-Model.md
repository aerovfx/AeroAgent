# Fine-Tuning một mô hình GPT

## Giới thiệu

Chào mừng quay lại! Bây giờ chúng ta sẽ thực sự tạo fine-tuning job.

## Chọn Model để Fine-tune

Theo tài liệu OpenAI, các model có sẵn cho fine-tuning:
- `gpt-4o`
- `gpt-4o-mini`
- `gpt-4`
- `gpt-3.5-turbo`

Chúng ta sẽ sử dụng **gpt-4o** - model mới nhất.

## Tạo Fine-tuning Job

```python
response = client.fine_tuning.jobs.create(
    training_file=train_file_id,
    validation_file=validation_file_id,
    model="gpt-4o-2024-08-06"
)

print("Fine-tuning Job ID:", response.id)
```

### Tham số bổ sung (tùy chọn):

```python
response = client.fine_tuning.jobs.create(
    training_file=train_file_id,
    validation_file=validation_file_id,
    model="gpt-4o-2024-08-06",
    suffix="linkedin-ztm"  # Tên tùy chỉnh cho model
)
```

**Giải thích:**
- `training_file`: ID của file training
- `validation_file`: ID của file validation
- `model`: Model base để fine-tune
- `suffix`: Hậu tố tên model (tùy chọn)

## Theo dõi tiến trình

### Trên Dashboard:
1. Vào **Fine-tuning** trong OpenAI Dashboard
2. Job sẽ chuyển qua các trạng thái:
   - `validating_files`: Đang xác thực file
   - `queued`: Đang chờ
   - `running`: Đang chạy
   - `succeeded`: Hoàn thành
   - `failed`: Thất bại

### Qua Email:
OpenAI sẽ gửi email khi:
- Job bắt đầu
- Job hoàn thành
- Job thất bại

## Thời gian chờ

**Quan trọng:** Fine-tuning job mất vài phút để hoàn thành (thường là 5-30 phút tùy thuộc vào lượng dữ liệu).

## Xem kết quả

```python
# Lấy thông tin job
job = client.fine_tuning.jobs.retrieve(response.id)
print("Status:", job.status)
print("Fine-tuned model:", job.fine_tuned_model)
```

## Lấy Model ID để sử dụng

```python
# Lấy model đã fine-tune
fine_tuned_model = job.fine_tuned_model
print("Model để sử dụng:", fine_tuned_model)
```

## Sử dụng Model đã Fine-tune

```python
response = client.chat.completions.create(
    model=fine_tuned_model,
    messages=[
        {"role": "system", "content": "Bạn là người viết LinkedIn..."},
        {"role": "user", "content": "Viết bài về khóa học AI mới"}
    ],
    temperature=0.7
)

print(response.choices[0].message.content)
```

## Tóm tắt

Bước này bao gồm:
1. ✅ Upload dữ liệu lên OpenAI
2. ✅ Tạo fine-tuning job
3. ⏳ Chờ hoàn thành
4. ✅ Sử dụng model đã fine-tune

**Lưu ý quan trọng:**
- Fine-tuning là một trong những thứ tốn kém nhất bạn có thể làm với AI
- Chi phí khoảng $25/1 triệu tokens cho training (GPT-4o)
- Bạn không muốn làm điều này nhiều lần
