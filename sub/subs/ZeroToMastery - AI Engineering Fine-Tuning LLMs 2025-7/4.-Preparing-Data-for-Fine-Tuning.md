# Chuẩn bị Dữ liệu cho Fine-Tuning

## Giới thiệu

Chào mừng quay lại! Trong video này, chúng ta sẽ lấy tất cả các bài đăng LinkedIn vào trong notebook Colab của chúng ta.

## Bước 1: Đọc các file LinkedIn Posts

Chúng ta sẽ bắt đầu bằng cách lấy tất cả các tên file hoặc tiêu đề files.

```python
path = "/content/LinkedIn posts"
files = os.listdir(path)
```

## Bước 2: Đọc nội dung từng file

Tiếp theo, chúng ta sẽ mở từng file và lưu trữ nội dung. Mục tiêu ở đây là chúng ta có thể kiểm tra bất kỳ bài đăng nào.

```python
posts = []

for p in files:
    with open(f"{path}/{p}", "r") as file:
        post_content = file.read()
        
    data = {
        "content": post_content
    }
    
    posts.append(data)
```

## Cấu trúc dữ liệu

Chúng ta có một dictionary vì bạn có thể muốn có thêm điều gì đó khác. Trong trường hợp này:
- **Content**: Nội dung bài đăng

## Xem dữ liệu mẫu

Sau khi chạy code, chúng ta có thể xem một bài đăng cụ thể:

```python
posts[0]['content']
```

Tất cả các bài đăng nên cảm thấy khác nhau - và chúng có - và đó là nó!
