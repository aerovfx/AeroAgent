# Test Model Fine-tuned

## Giới thiệu

Job fine-tuning đã hoàn thành thành công! Chúng ta đã nhận được email thông báo. Bây giờ hãy test model và xem kết quả.

## Lấy Model ID

```python
# Lấy job
job = client.fine_tuning.jobs.retrieve(fine_tuning_job_id)

# Lấy fine-tuned model ID
fine_tuned_model = job.fine_tuned_model
print("Fine-tuned model:", fine_tuned_model)
```

## Tạo Test Prompt

```python
user_prompt = """
Viết bài đăng LinkedIn về khóa học mới:
- Chủ đề: Launch khóa học Fine-tuning GPT
- Tham chiếu: GPT-4o model, fine-tuning, xây dựng model LinkedIn posts
- Mục tiêu: Giới thiệu như "Henry Ford của thế giới AI"
"""
```

## Tạo Messages

```python
messages = [
    {"role": "system", "content": "Bạn là người viết bài LinkedIn chuyên nghiệp..."},
    {"role": "user", "content": user_prompt}
]
```

## Test với Different Temperatures

### Temperature = 1.2 (Creative)

```python
response = client.chat.completions.create(
    model=fine_tuned_model,
    messages=messages,
    temperature=1.2
)
```

**Kết quả:** Output rất sáng tạo, có thể hơi "nonsense"

### Temperature = 1.1 (Balanced)

```python
response = client.chat.completions.create(
    model=fine_tuned_model,
    messages=messages,
    temperature=1.1
)
```

**Kết quả:** Cân bằng hơn, vẫn có sáng tạo nhưng có kiểm soát

### Temperature = 1.0 (Default)

```python
response = client.chat.completions.create(
    model=fine_tuned_model,
    messages=messages,
    temperature=1.0
)
```

**Kết quả:** Ổn định, có thể sử dụng được

## Nhận xét kết quả

### Đánh giá:
- Model đã học được phong cách viết
- Sử dụng cấu trúc một câu mỗi đoạn
- Có yếu tố "provocative" (gây tranh cãi)
- Có thể hơi "nonsense" ở temperature cao

### Điều chỉnh:
- Temperature 1.0-1.1 là phù hợp nhất cho LinkedIn posts
- Cần thêm dữ liệu để cải thiện

## Lưu ý về Số lượng Dữ liệu

- **Tối thiểu:** 10 examples (đã đạt)
- **Khuyến nghị:** 50-100 examples để có kết quả tốt hơn
