# Tạo Prompt cho Fine-Tuning

## Giới thiệu

Để thực hiện fine-tuning, chúng ta cần có ba thành phần:
1. **System prompt** - định nghĩa vai trò và phong cách
2. **User prompt (Query/Input)** - câu hỏi hoặc hướng dẫn đầu vào
3. **Output** - phản hồi mong đợi

## Vấn đề hiện tại

Trong trường hợp của chúng ta:
- **Output đã có:** Đây là các bài đăng LinkedIn
- **System prompt:** Có thể tạo một cái chung cho tất cả
- **User prompt:** Chúng ta KHÔNG có - đây là vấn đề cần giải quyết

## Giải pháp

Chúng ta cần **tái tạo** user prompt từ output có sẵn. Nghĩa là: "Prompt nào đã dẫn đến bài đăng này?"

### Bước 1: Định nghĩa System Prompt

System prompt cho việc tạo prompts:

```python
system_prompt_gen = """Bạn là một kỹ sư prompt và người tạo nội dung chuyên gia.
Phân tích các bài đăng và soạn thảo một prompt bao gồm:
- Chủ đề chính
- Bất kỳ tham chiếu nào có sẵn
Chỉ viết nội dung của prompt và không có gì khác."""
```

### Bước 2: Sử dụng GPT để tạo User Prompts

```python
for post in posts:
    response = client.chat.completions.create(
        model="gpt-4o",
        messages=[
            {"role": "system", "content": system_prompt_gen},
            {"role": "user", "content": post['content']}
        ]
    )
    
    user_prompt = response.choices[0].message.content
    print(user_prompt)
```

## Kết quả

Mỗi bài đăng LinkedIn sẽ được ghép với một user prompt tương ứng. Điều này cho phép chúng ta có bộ dữ liệu hoàn chỉnh với:
- System prompt (định nghĩa vai trò)
- User prompt (câu hỏi/đầu vào)
- Assistant response (bài đăng LinkedIn)
