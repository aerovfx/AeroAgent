# Tại Sao Chúng Ta Sử Dụng Đồ Thị Tính Toán (Computational Graph)?

## 📺 Tóm tắt Video

Video này giải thích lý do tại sao chúng ta cần sử dụng **đồ thị tính toán** (computational graph) trong mạng nơ-ron, cách nó giúp đơn giản hóa quá trình lan truyền ngược (backpropagation), và tối ưu hóa hiệu suất tính toán.

---

## 1. Vấn đề: Phương trình phức tạp khi có nhiều tham số

### Trường hợp đơn giản:
```
x * W1 → z1 = h
z1 * W2 → y_pred
```

### Trường hợp thực tế:
Trong mạng nơ-ron lớn với **hàng triệu/hàng tỷ tham số**, nếu viết thành một chuỗi phương trình dài như `x * W1 * W2 * W3 * ...`, đạo hàm sẽ rất phức tạp.

---

## 2. Giải pháp: Đồ thị tính toán (Computational Graph)

### Nguyên lý cơ bản:
Đồ thị tính toán giúp **phân rã phương trình lớn** thành các **phương trình nhỏ hơn, từng mô-đun**.

| Trước khi có đồ thị | Sau khi có đồ thị |
|---------------------|-------------------|
| `y_pred = x * W1 * W2` | `z1 = x * W1`, sau đó `y_pred = z1 * W2` |
| Đạo hàm dài, phức tạp | Đạo hàm từng bước ngắn gọn |

### Ví dụ cụ thể:

**Biểu diễn không có đồ thị:**
```
y_pred = x * W1 * W2
```

**Biểu diễn với đồ thị:**
```
z1 = x * W1  (lớp đầu vào)
y_pred = z1 * W2 + b2  (lớp đầu ra)
loss = (y_true - y_pred)^2  (hàm mất mát)
```

---

## 3. Lợi ích của Đồ thị tính toán

### ✅ 1. Đơn giản hóa Lan truyền ngược (Backpropagation)
- Áp dụng **quy tắc dây chuyền** (chain rule) dễ dàng hơn
- Tránh xử lý đạo hàm riêng phức tạp của chuỗi dài

### ✅ 2. Tiết kiệm thời gian & tài nguyên tính toán
```python
# Không cần tính lại cùng một giá trị nhiều lần
# Chỉ tính một lần và tái sử dụng
H = x * W1    # Tính một lần
dLoss_dW2   = loss(H) * dH_dW2  # Tái sử dụng H
```

### ✅ 3. Hỗ trợ song song (Parallelism)
- Nhiều phép tính có thể được thực hiện đồng thời
- Giảm thiểu tính toán dư thừa

---

## 4. Trong các framework AI (TensorFlow, PyTorch)

Khi bạn tạo một mô hình trong **TensorFlow** hoặc **PyTorch**, hệ thống tự động xây dựng **computational graph**:

```python
# TensorFlow/Keras example
model = Sequential([
    Dense(64, activation='relu'),   # Tự tạo node H
    Dense(10)                       # Tự tạo node đầu ra
])
```

**Sau đó**, khi bạn gọi `model.fit()`, hệ thống sẽ:
1. Tự động xây dựng computational graph
2. Tối ưu hóa việc tính đạo hàm riêng (gradient computation)
3. Thực hiện backpropagation hiệu quả hơn nhiều so với cách tính thủ công
