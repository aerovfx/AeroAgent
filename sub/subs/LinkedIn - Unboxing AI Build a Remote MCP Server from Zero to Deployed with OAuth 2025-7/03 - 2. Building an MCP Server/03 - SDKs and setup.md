# 03 - SDK và thiết lập

---

- Hãy xem nó thực sự hoạt động như thế nào.

Vì vậy, trước hết, có một số SDK khác nhau

bạn có thể sử dụng để xây dựng máy chủ MCP,

bạn có Python, bạn có Java,

bạn có JavaScript hoặc Node,

bạn có C-sharp, có rất nhiều chúng.

Và tất cả những thứ đó đều có sẵn

từ kho lưu trữ mô hình văn bản GitHub.

Vì vậy, ở đây, bạn sẽ thấy bên dưới Tổ chức,

bạn có TypeScript, Python, Java, Kotlin, C-sharp,

và còn nhiều thứ như vậy nữa xuất hiện mọi lúc.

Tôi đang sử dụng Python ở đây,

vì Python rất dễ làm việc,

thật dễ hiểu.

TypeScript rất hữu ích cho việc xây dựng một số thứ,

nhưng TypeScript cũng là một ngôn ngữ trừu tượng

điều đó đôi khi hơi khó để mò mẫm.

Và ngoài ra, TypeScript yêu cầu biên dịch,

trong khi Python thì không.

Vì vậy, để sử dụng kho lưu trữ này hoặc sử dụng SDK này,

bạn cần thiết lập một môi trường phát triển.

Và khi bạn thiết lập một môi trường phát triển,

trước tiên bạn cần phải có tất cả các phần phù hợp.

Và vì đây là máy chủ MCP

sẽ chạy và kết nối với các ứng dụng AI

trên máy tính của bạn,

bạn không thể sử dụng những thứ như GitHub Codespaces cho việc này,

bởi vì nếu bạn làm vậy thì GitHub Codespaces

ngồi ngoài thế giới,

và hệ thống cục bộ của bạn sẽ cố gắng truy cập mọi thứ

đó là ở địa phương.

Vì vậy đây là một trong những trường hợp hiếm hoi

nơi bạn thực sự phải chạy mọi thứ cục bộ trên máy tính.
